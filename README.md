# 🏡 Smart House Price Prediction System

An interactive Machine Learning web application that predicts estimated house prices based on area size (square feet) and the number of rooms. Built using Python, Pandas, Scikit-Learn, and Streamlit.

## ✨ Features

- **Instant Price Estimation:** Quick predictions based on Area (SqFt) and Rooms input.
- **Machine Learning Integration:** Uses `LinearRegression` trained on structured housing data.
- **Clean UI:** Simple and responsive web interface built with Streamlit.
- **Dynamic Dataset Handling:** Reads training data directly from `house_data.csv`.

---

## 🛠️ Tech Stack & Dependencies

- **Programming Language:** Python 3.x
- **Web Framework:** Streamlit
- **Machine Learning:** Scikit-Learn (`sklearn`)
- **Data Manipulation:** Pandas
